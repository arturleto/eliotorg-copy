# Копия сайта eliotorg.ru (ЭЛИОТОРГ)

Копия сайта https://eliotorg.ru/, снята 29.10.2026 для изучения рынка.
Сайт конкурента фирмы «РОСКОН»: пищевые масла, жиры, какао-продукты и заменители масла какао оптом.

## Что внутри
- 38 страниц: каталог (масла, какао, заменители масла какао), карточки товаров с ценами, статьи, доставка, документы, контакты, о компании.
- Все картинки, шрифты и иконки сайта.
- `ВЕСЬ_ТЕКСТ_САЙТА.txt`: текст всех страниц одним файлом.

## Как открыть
- В интернете: https://arturleto.github.io/eliotorg-copy/
- На компьютере: открыть `index.html` в браузере.
